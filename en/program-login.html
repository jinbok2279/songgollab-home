Login Status Board

An internal Chrome extension that shows sign-in and credential expiry status for more than 60 sites used across 11 projects. It alerts me when a connection drops.

InternalChrome extensionv1.0Ops · AI tools
FeaturesHow it worksGalleryDevelopment log
Why I built it

It started with a small annoyance

Several overnight jobs stopped because a login had expired. I built a board that helps me find the broken connection before spending time looking for a code bug.

Features

What it does

Problems firstSites needing attention appear above healthy connections.
What needs attention nowImportant connections have a clear place on the board.
Toolbar summaryCheck the summary from Chrome and receive desktop alerts.
Sign-in notesKeep reminders about sign-in methods without storing passwords.
Important accountsPin key accounts for early attention.
Expiry calendarSee approaching credential and trial expiry dates.

How it got here

  • v1.0First versionDashboard, toolbar summary, sign-in notes and expiry calendar.
  • NextCentral ControlPlans for status and voice alerts on the board.
  • NextBroader desktop checksPlans to cover more desktop tools and projects.
The board stores no passwords or API key values. It reports status; it does not enter passwords or silently extend sessions. Screens show example states. This is currently an internal Chrome extension.
