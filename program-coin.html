코인자동매매

업비트 계정과 연결해 코인 시장을 실시간으로 감시하고, 매수와 매도를 스스로 판단하는 Windows용 자동매매 프로그램입니다. 사용자는 투자금만 정하고, 위험 설정·종목 선택·매매 시점은 프로그램이 정해진 기준에 따라 처리합니다.

● 개발 중Windowsv0.3커머스 · 투자 연구
주요 기능동작 방식이미지개발 기록
Why · 왜 만들었나

불편에서 시작했습니다

화면 앞에 계속 앉아 있을 수 없어도, 감정 대신 정해진 규칙으로, 손실 한도와 원금 보호선이 지켜지는 자동매매를 하려고 만들었습니다.

ONE LINE

업비트 전 종목을 실시간 감시하고 6가지 지표로 판단. 투자금만 정하면 위험 관리는 자동으로.

Features · 주요 기능

할 수 있는 것

전 종목 실시간 감시거래대금 상위 종목으로 감시 목록을 만들고, 종목마다 단기·장기 점수를 매겨 매수 후보를 추천합니다.
1~5초 단위 이상 신호 감지체결 쏠림, 거래대금 급증, 호가 불균형을 초 단위로 잡아 점수에 반영합니다.
6가지 지표로 자동 판단이동평균·MACD·거래량·캔들 패턴·RSI·볼린저밴드를 합쳐 매수·보유·매도를 판단하고, 판단 근거를 화면에 그대로 보여 줍니다.
투자금 기준 자동 위험 관리모든 한도를 총자산 비율로 계산하고, 입출금 시 원금과 기준선을 다시 맞춥니다. 최대 보유 종목·종목당 비중·하루 매수 한도·하루 손실 한도·원금 보호선, 연속 손실 시 주문 크기 축소.
매매 방식 선택자동 주문 / 승인 후 주문 / 수동 매매 중 고릅니다.
하루 한 번 복기 리포트매일 아침 전날 매매 기록을 정리합니다.
안전 장치긴급 정지 버튼으로 즉시 멈추고 전량 청산. 출금 기능은 없고, API 키는 사용자 PC에만 저장되며 화면에는 끝자리만 표시합니다.
사용 환경Windows 10/11, 설치 파일 하나로 설치. 업비트 계정과 Open API 키(주문 권한 필요, 출금 권한 불필요), 인터넷 연결.
How it works · 동작 방식

이렇게 돌아갑니다

1전 종목 감시거래대금 상위
2이상 신호1~5초 단위
3지표 판단6가지 지표 점수
4위험 관리비율 한도 · 원금 보호선
5주문 · 복기자동·승인·수동, 아침 리포트
