투자비 관리

알리익스프레스·G마켓 구매 내역을 프로젝트별로 자동 분류하고, 월별로 얼마 썼는지 한눈에 보는 Windows 프로그램입니다. 매주 주문 내역이 자동으로 쌓이고, 사람은 '확인 필요' 몇 건만 보면 됩니다.

● 사용 중Windowsv2.0운영 · AI 도구

Why · 왜 만들었나

불편에서 시작했습니다

홈IoT, 드라이브 콘솔, AI 비전카메라, 3D프린터, 온실 같은 프로젝트를 동시에 진행하면서 부품은 대부분 해외직구로 삽니다. 몇 달 지나면 "이 센서는 어느 프로젝트에 쓴 거였지?", "이번 달 홈IoT에만 얼마 들었지?"를 알기 어려워졌습니다. 주문 내역을 엑셀에 옮겨 적는 대신, 매주 자동으로 모으고 프로젝트별로 나눠 주는 프로그램을 만들었습니다.

Features · 주요 기능

할 수 있는 것

대시보드월·프로젝트·구매처로 걸러 보고, 이번 달 합계·구매 건수·가장 많이 쓴 프로젝트·확인 필요 건수를 한 화면에. 표에서 프로젝트를 바로 바꾸면 다음 업데이트 때도 유지됩니다.
분석 — 숫자 대신 문장으로월말 예상, 직전 3개월 평균, 누적 투자. "전월보다 12% 늘었어요", "이 속도면 예산을 넘어요"처럼 문장으로 알려 줍니다.
프로젝트별 예산월 예산을 넣으면 사용률 막대로 보여 주고, 프로젝트 × 월 표와 고액 지출 TOP 10을 함께 봅니다.
매주 자동 업데이트주문 수집 → 키워드 규칙 + AI 분류 → 드라이브 저장 → 프로그램이 1분마다 확인해 반영. 중복은 걸러지고 취소 주문은 지워집니다.
중앙관제 연동이번 달 합계, 프로젝트별 합계, 확인 필요 건수, 예산 초과 경고를 관제실로 보냅니다.
이런 분께여러 DIY·IoT 프로젝트를 하며 해외직구를 자주 하는 분, 프로젝트별 원가를 알고 싶은 1인 사업자·메이커.
How it works · 동작 방식

이렇게 돌아갑니다

1주문 내역 수집매주 알리·G마켓 최근 14일
