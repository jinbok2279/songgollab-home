Why · 왜 만들었나

불편에서 시작했습니다

프로그램을 여러 개 운영하다 보니 어느 사이트 로그인이 풀렸는지, 어떤 키가 곧 만료되는지 몰라 작업이 자주 멈췄습니다.

ONE LINE

여러 사이트의 로그인 상태와 키 만료일을 한눈에. 복구 수단 점검표 포함.

Features · 주요 기능

할 수 있는 것

로그인 상태 한눈에사이트별 로그인 여부를 초록·노랑·회색으로 보여 줍니다.
키 · 토큰 만료일만료일을 넣어 두면 다가올 때 알려 줍니다.
복구 수단 점검표복구 전화·메일·백업 코드·2단계 인증을 하나씩 확인합니다.
확인함 기록확장이 볼 수 없는 앱은 열어 보고 "확인함"을 누르면 14일 뒤 다시 알려 줍니다.
