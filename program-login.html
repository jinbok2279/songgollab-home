로그인 상태 점검판

Why · 왜 만들었나

불편에서 시작했습니다

송골랩의 프로젝트는 대부분 밤사이나 정해진 시간에 혼자 돌아가는 자동화예요. 그런데 멈춘 이유를 찾아보면 코드 문제가 아니라 어딘가 로그인이 끊겨 있는 경우가 많았어요. 앱 세션 만료, 7일 만에 풀린 구글 연결, 기한이 지난 API 키… 한 달 사이에 두 번이나 이것 때문에 작업이 통째로 멈췄어요. 그래서 "어디가 끊겼는지 한 화면에서 보고, 끊기면 바로 알려 주는" 도구를 직접 만들었어요.

Features · 주요 기능

할 수 있는 것

한눈에 보는 점검판모든 사이트를 끊김 · 확인 필요 · 만료 임박 · 정상 네 가지로 나눠 보여 주고, 문제 있는 곳이 항상 맨 위로 올라와요.
「지금 챙길 것」끊기면 모든 자동화가 멈추는 「바탕」 항목은 따로 띄우고, 바로 열어서 로그인하는 버튼을 붙였어요.
툴바에서 바로 확인끊긴 곳이 있으면 아이콘에 빨간 숫자, 새로 끊기면 Windows 알림. 10분마다 자동 점검하고 로그인·로그아웃 3초 뒤 다시 확인해요.
로그인 방법 기록사이트마다 로그인 방법, 어느 계정, 비번 금고 저장 여부, 2단계 인증 종류를 적어 둬요. 금고에 없는 곳은 빨간 표시.
구글 계정 복구 점검대부분의 로그인이 묶인 구글 계정 두 개의 복구 전화·복구 이메일·백업 코드 준비 여부를 맨 위에 고정했어요.
API 키 만료 달력API 키·토큰·무료 체험 기한을 D-day로 계산하고, 14일 전부터 「만료 임박」으로 바꿔 알려 줘요.
How it works · 동작 방식

이렇게 돌아갑니다

1쿠키 (자동)그 사이트의 로그인 쿠키와 만료일 확인
2접속 (자동)집 안 서버에 접속되는지 확인
3만료일키·토큰·체험 기간을 D-day로
4직접 확인앱·CLI는 열어 보고 「확인함」, 2주 뒤 다시 알림

Log · 개발 기록

어떻게 만들어 왔나

  • v1.0첫 버전점검판, 툴바 팝업, 로그인 방법 기록, 구글 복구 점검, API 키 탭과 만료 달력.
  • 다음중앙관제 연동점검 결과를 관제실로 보내 끊기면 음성으로 알려 주게 할 예정이에요.
  • 다음PC 점검 자동화 · 새 프로젝트 자동 등록데스크톱 앱·CLI 로그인·드라이브 동기화·절전 모드를 관제 PC가 직접 확인하고, 새 프로젝트의 사이트를 같은 양식으로 합쳐요.
이 프로그램에는 비밀번호와 API 키 값을 절대 저장하지 않아요. 비밀번호는 전용 금고에만 두고, 점검판은 "어디에, 어떻게"만 기억해요. 비밀번호를 대신 입력하거나 세션을 몰래 연장하지 않고, 상태를 보고 알려 주는 것까지만 해요. 화면 속 상태값은 예시이며, 지금은 송골랩 내부용 Chrome 확장(v1.0)입니다.
