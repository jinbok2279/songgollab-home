3D Print Bench

3D 프린터를 PC 한 화면에서 보고, 맡기고, 안전하게 돌리는 Windows 프로그램입니다. 출력 상태 확인부터 작업 대기열, 자동 슬라이스, 필라멘트 관리, 점검까지 한곳에서 합니다. 클라우드 없이 집 안 네트워크에서만 동작하고, 화면은 모두 한국어입니다.

● 개발 중Windowsv0.9IoT · 자동화
주요 기능동작 방식안전장치이미지영상자료개발 기록
Why · 왜 만들었나

불편에서 시작했습니다

3D 프린터는 출력 한 번에 몇 시간씩 걸립니다. 그동안 프린터 앞을 지키거나, 프린터 화면과 슬라이서를 오가며 확인해야 했습니다. 중고 프린터를 들인 날 바로 만들기 시작해, 그 일을 PC 한 화면으로 모았습니다.

Features · 주요 기능

할 수 있는 것

실시간 모니터링진행률, 남은 시간, 완료 예상 시각, 노즐·베드 온도와 그래프. 실제 출력 경로를 프린터 그림 안에서 3D로 보여 줍니다.
작업 대기열 · 자동 슬라이스파일을 쌓아 두면 프린터가 비는 대로 순서대로 보냅니다. STL·3MF는 OrcaSlicer로 자동 슬라이스합니다.
출력 전 미리보기설계 배치도, 슬라이스 결과, 첫 레이어를 그림으로 확인하고 층별 경로를 슬라이더로 봅니다.
여러 대 · 필라멘트 관리프린터 여러 대에 작업을 나눠 보내고, 롤 용량을 등록하면 출력할 때마다 남은 양을 계산합니다.
점검 · 캘리브레이션베드를 데운 뒤 레벨링·진동 보정을 한 번에 하는 전체 자가 점검, 통신·팬·가열을 확인하는 건강 점검.
야간 조용 출력 · 자동 절전밤에는 출력 속도를 자동으로 낮추고, 출력이 없으면 히터·팬·조명을 끕니다. 휴대폰·ESP32-CAM을 카메라로 씁니다.
How it works · 동작 방식

이렇게 돌아갑니다

1파일 넣기G-code · STL · 3MF
2자동 슬라이스미리보기 그림 생성
3인터락 점검재료 · 온도 · 기종 · 노즐 · 잔량
4출력베드 비움 확인 후 시작
5모니터링필라멘트 자동 차감 · 완료 알림
Safety · 안전장치

출력 전에 막아 주는 안전장치 (인터락)

재료PLA용 G-code를 PETG가 걸린 프린터에서 시작하려 하면 막습니다.
온도재료별 안전 범위를 벗어난 노즐·베드 온도면 막습니다.
기종 · 노즐다른 기종용 G-code나 노즐 지름이 다르면 막습니다.
잔량남은 필라멘트가 모자랄 것 같으면 막습니다.
가장자리첫 레이어가 베드 끝까지 오면 알려 줍니다.
막힌 이유를 그대로확인창에 이유를 보여 주고, 꼭 필요하면 한 번 더 확인한 뒤 시작합니다. 그 기록이 남습니다.

사용 환경 · Windows 10/11 64비트 · Creality K 계열 순정 펌웨어(K1에서 확인), Klipper·Bambu Lab은 준비 중 · PC와 프린터가 같은 공유기 · 자동 슬라이스는 OrcaSlicer 필요 · 인터넷은 모델 찾기에만 사용
