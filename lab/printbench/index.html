3D Print Bench

3D 프린터 작업을 한 프로그램에서.

프린터 상태 보기, 3D 모델 미리보기, 간단한 모델링, 출력 비용 계산을 한 Windows 프로그램에 모았습니다.

왜 만들었나

직접 만들 부품이 많아졌습니다

집 안 로봇과 장치 부품을 직접 만들려고 3D 프린터를 들였습니다.

프린터 확인, 모델 보기, 비용 계산이 여러 프로그램에 흩어져 있어서 한곳에 모으고 있습니다.

할 수 있는 것

01

프린터 상태 보기

멀리서도 출력 진행과 프린터 상태를 봅니다.

02

3D 모델 미리보기

출력하기 전에 모델을 돌려 보며 확인합니다.

03

작업 대기열

출력할 파일을 순서대로 모아 둡니다.

04

출력 비용 계산

재료와 시간으로 한 번 출력에 드는 비용을 계산합니다.
