로그인 상태 점검판

왜 만들었나

코드 문제가 아니라 로그인 문제였습니다

송골랩 프로젝트는 대부분 밤사이나 정해진 시간에 혼자 돌아가는 자동화입니다. 멈춘 이유를 찾아보면 코드가 아니라 어딘가 로그인이 끊겨 있는 경우가 많았습니다.

그래서 어디가 끊겼는지 한 화면에서 보고, 끊기면 바로 알려 주는 도구를 직접 만들었습니다.

할 수 있는 것

01

한눈에 보는 점검판

끊김 · 확인 필요 · 만료 임박 · 정상으로 나누고, 문제 있는 곳이 맨 위로.

02

툴바에서 바로 확인

끊긴 곳이 있으면 아이콘에 숫자, 새로 끊기면 알림.

03

만료 달력

API 키·체험 기한을 D-day로 계산해 14일 전부터 알려 줍니다.

04

비밀번호는 저장하지 않음

비밀번호와 키 값은 저장하지 않고, 상태를 보고 알려 주는 것까지만 합니다.

화면 속 상태값은 예시입니다.
