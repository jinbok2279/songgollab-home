드라이브 콘솔 개발 기록

집에서 쉬고 있는 태블릿을 내 차의 대시보드·내비·진단기로. 3D 계기판, T맵 분할 화면, 인터넷 라디오, 음성 비서, OBD 차량 진단을 태블릿 하나에 담았습니다. 실제 차(2017 올뉴K7 3.0 LPi)에서 OBD 연결과 고장 코드 읽기까지 확인했습니다.

v1.3 새 기능: 연료에 맞춘 진단

디젤DPF 차압·재생 필요도, 커먼레일 압력·EGR·과급압·요소수, 관련 코드 약 100개
LPi올뉴K7 3.0 LPi 전용 기준, LPG 펌프·필터·펌프 드라이버 원인 분석

연료는 차량 등록에서 고른 값을 먼저 쓰고, 없으면 ECU가 알려 주는 연료 종류로 자동 판별합니다.

차량 – 동글 – 태블릿

2OBD 동글운전석 아래 단자에 꽂는 ELM327 동글, 블루투스 또는 Wi-Fi

4태블릿 안에서 처리차량 데이터는 외부 서버로 보내지 않습니다

개발 일지

어떻게 만들어 왔나

  • v0.6시작 — 대시보드 화면 기본 틀처음 손에 있던 건 v0.6 설치 파일 하나였습니다. 여기서부터 화면과 기능을 하나씩 쌓았습니다.
  • v0.9계기판과 분할 화면3D 계기판 7종, 분할 화면 아래 작은 메뉴(7:3·5:5·3:7), 6개 언어. 가짜 데이터는 모두 걷어 냈습니다.
  • v1.0Wi-Fi OBD 연결OBD 동글에서 회전수·차속·냉각수·배터리 같은 실시간 값을 받아, 순간·평균 연비와 주행 가능 거리를 계산합니다.
  • v1.0.1 ~ v1.0.11분할과 음성 비서 다듬기왼쪽 T맵 고정 분할, 분할 잠금, 화면 위에 뜨는 음성 비서 링, 앱 안 음성 인식, 시간대별 배경과 일주일 날씨, 떠 있는 창 지원까지 열한 번 고쳤습니다.
  • v1.1블루투스 동글과 차량 정보블루투스 OBD 동글을 연결하고, 건강 점수·상황별 판정·원인 추정·내 차 평소값 학습을 담은 "차량 정보" 메뉴를 만들었습니다.
  • v1.2메인 화면 개편과 인터넷 라디오왼쪽 차량 상태 패널, 도로 위 3D 차량, 8개 채널 라디오. 다른 화면에서도 라디오가 계속 나옵니다.
  • v1.2.1고장 코드 전부 해석올뉴K7 상세 코드 427개와 국제 표준 9,415개를 한국어로. 엔진 외 8개 장치 고장 코드도 읽습니다.
  • v1.2.2 ~ v1.2.3안전 먼저주행 중 영상 가림막, 화면 전환 정리, 음성 비서 창이 T맵을 가리지 않게. 버튼 75개를 자동 점검해 오류 0건을 확인했습니다.
  • v1.3가솔린·디젤·LPi 모두 지원연료 자동 판별, 디젤 전용 값과 연료별 정비 사전을 더하고, 설명 문구를 전부 다시 검토했습니다.
  • v1.3.1분할 종료 수정분할을 끝내면 앱이 앞에 뜰 때까지 확인하고 메인 화면으로 바로 돌아옵니다.
  • v1.3.53부르는 이름 바꾸기 · 안전 운전 안내음성 비서를 부르는 이름(기본 "송골랩")을 바꿀 수 있고, 처음 실행하면 안전 운전 안내가 한 번 뜹니다.
  • 다음실차 검증 → 출시디젤·가솔린 차로 기준값 보정, 라디오 운영 방식 결정, KC 인증 동글과 함께 파는 패키지, Play 스토어 정책에 맞춘 배포를 준비합니다.
