무료 체험은 이렇게 진행됩니다

  1. 01

    설치

    다운로드한 설치 파일을 실행해 설치합니다.

  2. 02

    처음 실행

    처음 실행할 때 인터넷 연결과 이메일 입력이 필요합니다. 만료 안내를 보내 드리기 위해서입니다.

  3. 03

    30일 체험

    30일 동안 모든 기능을 제한 없이 쓸 수 있습니다. 만료 3일 전에 프로그램에서 알려 드립니다.

  4. 04

    체험 후

    체험이 끝나도 작업한 파일은 그대로 남아 있습니다.

체험판은 이메일, 암호화된 기기 식별값, 프로그램 사용 기록(실행 횟수·사용 시간·사용 기능)을 수집합니다. 작업한 파일과 자료는 PC에만 저장되고 송골랩으로 보내지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

"Windows의 PC 보호" 파란 창이 떠요.

송골랩은 작은 개발사라 아직 마이크로소프트 서명 인증서가 없어서 나오는 안내입니다. [추가 정보] → [실행]을 누르면 설치됩니다.

인터넷 없이도 쓸 수 있나요?

처음 실행할 때만 인터넷이 필요합니다. 그 뒤로는 최대 3일까지 인터넷 없이 쓸 수 있고, 연결되면 자동으로 다시 확인합니다.

다른 PC에 설치하면 체험 기간이 새로 시작되나요?

체험 기간은 PC마다 따로 계산됩니다. 같은 PC에서 지웠다가 다시 설치해도 체험 기간은 처음부터 다시 시작되지 않습니다.

체험이 끝나면 어떻게 하나요?

정식 버전 판매는 준비 중입니다. 문의: songgollab@gmail.com

내 정보를 지우고 싶어요.

프로그램을 지우려면?

Windows 설정 → 앱 → 설치된 앱에서 프로그램을 찾아 제거합니다.

안드로이드 APK는 어떻게 설치하나요?

플레이스토어 밖에서 받은 APK는 처음 열 때 '출처를 알 수 없는 앱 설치'를 허용해야 설치됩니다. 설치가 끝나면 다시 꺼 두어도 됩니다.
