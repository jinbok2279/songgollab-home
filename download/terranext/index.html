TerraNext 테라넥스트

토지·부동산 종합정보 분석 시스템

땅을 팔라는 연락이 왔을 때, 상대가 알고 오는 정보를 나도 먼저 확인할 수 있게 도와주는 Windows 프로그램입니다. 흩어져 있는 공공데이터(공시지가, 용도지역, 개발구역, 실거래, 건축 허가, 공고 등)를 한곳에 모아 쉬운 말로 정리해 보여 줍니다.

설치파일 준비 중

곧 올라옵니다.

TerraNext는 공공데이터를 모아 정리해 보여 주는 정보 프로그램이며, 감정평가가 아닙니다. 표시되는 정보는 각 기관의 공개 자료 기준이며, 자료 기준일과 실제가 다를 수 있습니다. 실제 거래 전에는 등기부등본·토지이용계획 원본 확인과 전문가 상담을 권합니다.

등록한 땅, 등기부 PDF, 인증키, 보고서는 사용자 PC에만 저장됩니다. 송골랩 서버로 보내는 정보는 체험판 관리에 필요한 이메일·기기 식별값(암호화)·사용 기록뿐입니다.

설치 방법

설치하고 시작하기

  1. 무료 체험판 다운로드 버튼을 눌러 설치파일을 받습니다.
  2. 설치파일을 실행합니다. Windows가 "PC 보호" 창을 띄우면 추가 정보 → 실행을 누르세요.
  3. 설치가 끝나면 TerraNext를 실행합니다.
  4. 첫 실행 때 이메일을 입력하고 개인정보 수집에 동의하면 30일 체험이 시작됩니다.
  5. [환경설정]에 브이월드·공공데이터포털 인증키를 넣으면 조회를 시작할 수 있습니다.

무료 체험 안내

30일 동안 모든 기능

  • 30일 무료 체험 (체험 기간은 송골랩 관리자 설정에 따릅니다)
  • 처음 실행할 때 인터넷 연결과 이메일 입력이 필요합니다.
  • 체험 중에는 인터넷이 끊겨도 최대 3일까지 사용할 수 있습니다.
  • 체험 기간이 끝나면 라이선스 키 입력 화면이 나옵니다. 정식판 안내는 준비 중입니다.
  • 체험이 끝나거나 종료돼도 사용자가 등록한 땅·등기부·보고서 자료는 지워지지 않습니다.

개인정보 수집 안내

사용 현황 확인과 만료 안내를 위해 이메일, 기기 식별값(암호화), 실행 횟수·사용 시간·기능 사용 기록을 수집합니다. 체험 종료 후 1년간 보관하며 그 외 용도로 사용하지 않습니다.

자주 묻는 질문

궁금한 점

"Windows의 PC 보호" 파란 창이 떠요.

설치파일에 코드 서명이 없어서 나오는 안내입니다. [추가 정보] → [실행]을 누르면 설치가 진행됩니다. 다운로드 파일이 맞는지는 아래 SHA-256 값으로 확인할 수 있습니다.

인증키가 꼭 있어야 하나요?

브이월드와 공공데이터포털 키는 필수입니다. 나머지는 선택이고, 뉴스와 국토부 보도자료는 키 없이도 받습니다.

내 땅 정보가 송골랩으로 가나요?

아니요. 등록한 땅, 등기부 PDF, 인증키, 보고서는 사용자 PC에만 저장됩니다. 송골랩으로 보내는 정보는 체험판 관리에 필요한 이메일·기기 식별값(암호화)·사용 기록뿐입니다.

새 버전은 어떻게 설치하나요?

새 버전 설치파일을 그대로 실행하면 덮어 설치되고, 등록한 자료와 인증키는 그대로 남습니다.
