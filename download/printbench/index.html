SonggolLab 3D Print Bench

3D 프린터 여러 대를 한 화면에서 보고, 맡기고, 안전하게 돌리는 Windows 통합 관제 프로그램

프린터 앞을 지키지 않아도 됩니다. 출력 상태·온도·남은 시간·카메라 영상을 한 화면에서 보고, 출력 전에 재료·온도·노즐이 맞지 않으면 프로그램이 먼저 막아 줍니다.

무료 체험판 다운로드 (Windows · 53.5MB)

v0.10.2 · 2026-11-25 · Windows 10/11 64비트 · 30일 무료 체험

이런 분께 맞습니다

이런 분께

  • 3D 프린터를 1대 이상 운영하면서 출력 상태를 자주 확인해야 하는 분
  • PLA·PETG 등 재료를 바꿔 쓰다가 설정 실수로 출력이 실패해 본 분
  • 출력 작업을 쌓아 두고 순서대로 돌리고 싶은 분
  • 남는 휴대폰을 프린터 카메라로 쓰고 싶은 분

주요 기능

할 수 있는 것

통합 관제

프린터 전체 현황, 출력 중·대기·확인 필요 대수, 가동률, 성공률, 금월 생산 요약, 최근 알림을 한 화면에.

프린터 상세

실제 프린터 사진 위에 출력 경로가 층층이 쌓이는 화면, 진행률·남은 시간·노즐/베드 온도 그래프, 일시정지·정지·속도·팬·조명 제어.

작업 관리

파일을 창에 끌어다 놓으면 대기열에 추가. STL·3MF는 OrcaSlicer로 자동 슬라이스. 대기·진행 / 완료 / 실패·취소를 따로 보관.

출력 전 안전 검사(인터락)

재료·온도·기종·노즐 지름·필라멘트 잔량이 맞지 않으면 출력 시작을 막고 이유를 보여줍니다. 베드 가장자리에 너무 붙은 출력물은 경고합니다.

영상 관제

남는 휴대폰(IP Webcam 앱)이나 ESP32-CAM을 프린터 카메라로. 1·4·9·16분할, 화면 회전 지원.

재료 관리

프린터별 필라멘트 롤 등록, 출력할 때마다 남은 양 자동 차감, 100g 이하 경고.

생산 분석

완료·실패·취소 건수, 성공률, 출력 시간, 재료 사용량을 프린터별·재료별로. CSV 내보내기.

모델 라이브러리

모델을 검색해 3D로 미리 보고 바로 출력 대기열로. 내 PC의 파일도 열 수 있습니다.

장비 진단

베드 데움→레벨링→진동 보정을 버튼 하나로 하는 전체 자가 점검, 통신·카메라·팬·가열 건강 점검과 이력, 통신 로그.

시스템 설정

프린터 연결, 카메라, 슬라이서, 야간 조용 출력(밤에 속도 자동 감속), 대기 절전(쉬는 동안 히터·팬·조명 끄기), 인터락 항목 켜고 끄기.

노트북 화면에서도

노트북 화면(1366×768)에서는 메뉴가 아이콘으로 접히고 배치가 자동으로 바뀝니다. (시연 모드 · 예시 데이터)

지원 환경

이런 환경에서 돌아갑니다

운영체제Windows 10 / 11 (64비트)
지원 프린터Creality K 계열 (순정 펌웨어, 같은 공유기 연결) — K1에서 실사용 확인
준비 중Bambu Lab, Klipper(Moonraker) 계열 — 화면에는 "준비 중"으로 표시
자동 슬라이스OrcaSlicer 설치 시 사용 가능 (G-code만 쓰면 필요 없음)
카메라 (선택)휴대폰 IP Webcam 앱, ESP32-CAM 등 MJPEG 카메라
인터넷체험판 확인용으로 첫 실행 때 필요. 이후 3일까지는 인터넷 없이도 실행

설치 방법

설치하고 시작하기

  1. 무료 체험판 다운로드 버튼을 눌러 설치파일을 받습니다.
  2. 설치파일을 실행합니다. Windows가 "PC 보호" 창을 띄우면 추가 정보 → 실행을 누르세요.
  3. 설치가 끝나면 바탕화면의 SonggolLab 3D Print Bench를 실행합니다.
  4. 첫 실행 때 이메일을 입력하고 개인정보 수집에 동의하면 30일 체험이 시작됩니다.

무료 체험 안내

30일 동안 모든 기능

  • 설치 후 30일 동안 모든 기능을 쓸 수 있습니다.
  • 체험이 끝나면 라이선스 키를 입력해 정식 버전으로 전환할 수 있습니다. 정식 버전 문의는 songgollab@gmail.com으로 해 주세요.
  • 체험이 끝나도 작업 파일과 설정은 지워지지 않습니다.

개인정보 수집 안내

사용 현황 확인과 만료 안내를 위해 이메일, 기기 식별값(암호화), 실행 횟수·사용 시간·기능 사용 기록을 수집합니다. 체험 종료 후 1년간 보관하며 그 외 용도로 사용하지 않습니다.

자주 묻는 질문

궁금한 점

프린터 계정이나 클라우드 가입이 필요한가요?

아니요. 프린터와 같은 공유기에 있으면 직접 연결합니다.

프린터 펌웨어를 바꿔야 하나요?

아니요. Creality K 계열 순정 펌웨어 그대로 씁니다.

인터넷이 없으면 못 쓰나요?

첫 실행 때만 필요하고, 이후 3일까지는 인터넷 없이 실행됩니다.

Bambu Lab 프린터도 되나요?

지금은 준비 중입니다. 지원되면 홈페이지에 먼저 알려 드립니다.

"Windows의 PC 보호" 파란 창이 떠요.

코드 서명 인증서가 아직 없어서 나오는 안내입니다. [추가 정보] → [실행]을 누르면 설치됩니다.
