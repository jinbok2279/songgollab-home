송골트레이더

키움 모의 · 토스 실전 주식과 업비트 코인을 한 프로그램, 한 화면에서 관리하는 Windows용 자동매매 관제 프로그램입니다. 따로 쓰던 주식 자동매매와 코인 자동매매를 송골트레이더 하나로 합쳤습니다. 시장마다 엔진은 따로 돌고, 사람은 한 화면에서 모두 봅니다.

● 개발 중Windowsv0.3.0커머스 · 투자 연구
주요 기능동작 방식안전장치이미지개발 기록
Why · 왜 만들었나

불편에서 시작했습니다

주식 프로그램과 코인 프로그램을 따로 켜 두니 창도, 설정도, 복기도 두 벌이었습니다. 시장은 달라도 보는 사람은 한 명이라서, 화면은 하나로 모으고 엔진은 시장별로 분리해 서로 영향을 주지 않게 만들었습니다.

Features · 주요 기능

할 수 있는 것

네온 BUY / SELL 레이더매수 후보는 왼쪽 초록 영역, 매도 신호는 오른쪽 빨간 영역에 점으로 찍힙니다. 가운데에 가까울수록 신호가 강합니다. 위쪽 탭으로 키움 모의 · 토스 실전 · 업비트 코인을 바꿔 봅니다.
차트 · 호가 · 체결감시 종목의 분봉 차트, 이동평균, 매수·매도 표시, 거래량과 체결강도를 한 화면에서 봅니다.
수익률 현황누적·오늘·이번 달 수익률, 자산 추이, 일별 손익과 승률을 시장별로 정리합니다.
복기 회의 — Claude AI장이 끝나면 Claude가 그날 매매를 정리하고, 매수 전 심사(진행·보류)의 결과를 30분 뒤 수익률로 다시 확인합니다.
분석 · 감지 기록 · 매매 기록거래량 급증·호가 불균형·체결 쏠림 같은 감지 신호가 실제로 맞았는지 1분·5분·30분 뒤 수익률로 검증하고, 체결 내역을 남깁니다.
보유 종목 자동 / 직접종목마다 프로그램에 맡길지(자동), 내가 직접 할지(직접)를 버튼 하나로 바꿉니다.
설정 — API 연결 · 위험 한도증권사·거래소 키 연결, 1회 주문·종목당 최대·하루 매수 합계·하루 손실 한도·원금 보호선·진입 점수를 항목별로 정합니다.
How it works · 동작 방식

이렇게 돌아갑니다

1시세 수신주식 · 코인 시장별 엔진
2신호 감지거래량 · 호가 · 체결
3점수 · 심사진입 점수 · Claude 심사
4주문 · 한도자동 · 직접, 위험 한도
5복기수익률 · 복기 회의
Safety · 안전장치

돈이 걸린 프로그램이라 먼저 막아 둔 것

출금 기능 없음프로그램에는 출금 기능이 아예 없습니다.
손실 한도 · 원금 보호선하루 손실 한도나 원금 보호선에 닿으면 그날 신규 매수를 멈춥니다.
엔진 중복 실행 방지같은 시장 엔진이 두 번 켜지지 않습니다.
바꾸기 전 확인설정을 바꿀 때 바뀌기 전 → 후 값을 보여 주고 확인을 받습니다.
긴급 정지 · 전량 청산버튼 하나로 모든 엔진을 멈추고 보유분을 정리합니다.
토스 실전은 따로실전 계좌는 별도 한도로 운영하고, 관제 화면은 주문을 보내지 않습니다.

사용 환경 · Windows 10/11 64비트, 설치 파일 하나. 키는 이 PC에만 Windows 보호 기능(DPAPI)으로 암호화해 저장합니다.

Log · 개발 기록

어떻게 만들어 왔나

  • 주식 v0.4주식 자동매매 따로 개발키움 모의로 검증, 금감원 공시 연동, 장 마감 복기.
  • 코인 v0.3코인 자동매매 따로 개발업비트 전 종목 감시, 매매 실험실.
  • v0.3.0송골트레이더로 통합네온 레이더 대시보드, Claude 복기 회의, 시장별 엔진 분리 (2026-11).
화면 사진의 종목·금액·수익률은 기능을 보여 드리기 위한 예시입니다. 본 프로그램은 매매를 돕는 도구이며 수익을 보장하지 않습니다. 자동매매는 원금 손실이 생길 수 있으며, 투자 판단과 결과에 대한 책임은 사용자 본인에게 있습니다. 처음에는 모의투자로 충분히 확인한 뒤 실전에 쓰시기를 권합니다.
